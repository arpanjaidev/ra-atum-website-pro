The Node Operator Platform provides a controlled path from candidate enrollment to qualification and validator participation without exposing private validator infrastructure.

Operator Application
Portable operator releases support the candidate setup and connection workflow.
Candidate Enrollment
Each candidate receives a distinct lifecycle identity rather than an assumed validator role.
HEKA127 Qualification
Evidence-based checks evaluate readiness, integrity and expected network behavior.
Signed Profile
Connection configuration is signed and fail-closed when authority evidence is missing.
Controlled Activation
A qualified candidate becomes an active validator only through explicit approved activation.
No Private Keys
Public downloads and portal routes must never contain validator private directories or signing secrets.
Verified Boundaries
  • Candidate → Qualification → Approval → Active Validator
  • Fail-closed connection profile
  • No automatic membership mutation
  • Portal changes do not restart validators
