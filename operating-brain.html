What is RA Atum?

RA ATUM is an original Layer-1 blockchain with a C++ core and a reasoned operating layer.
• HEKA127 evaluates node and network evidence without holding private keys.
• Its advice does not replace signed validator membership or finality.
• Decision inputs, reasons, and resulting state can be recorded for auditability.
• The current environment is a working, controlled multi-validator testnet.

C++ Layer-1 Core RA ATUM owns its ledger, asset rules, validation flow, and finalized state.
Reasoned Advice HEKA127 produces an explainable recommendation from available evidence.
Validator Authority Signed membership and consensus remain authoritative for network decisions.
Fail-Closed Security Missing evidence never becomes automatic qualification or approval.
Evidence Records Reasons and finalized outcomes remain inspectable through network evidence.
Working Testnet HEKA127 is being exercised with a controlled five-validator topology.
No Key Custody The Operating Brain never asks for, stores, or signs with operator private keys.
Qualification Flow Candidate, qualification, approval, and active validator are distinct states.
How it Works
  • Observe: Read candidate, node, and network evidence.
  • Advise: HEKA127 returns a reasoned qualification recommendation.
  • Approve: Authorized membership applies the admission policy.
  • Finalize: Validators decide and record canonical state.
