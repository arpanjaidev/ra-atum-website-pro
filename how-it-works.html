How RA ATUM Works

RA ATUM Website Pro

A transaction moves through the wallet platform, HEKA127 evidence path and deterministic blockchain core before validators finalize it. Intelligence supports the process; it does not bypass consensus.

1. Wallet
A user or application prepares an RA ATUM transaction with the correct asset, recipient, amount and nonce.
2. Wallet Engine
The wallet engine validates structure and prepares the transaction for the network path.
3. HEKA127
The Operating Brain observes context and records a reasoned advisory report where applicable.
4. Bridge
The controlled bridge carries the accepted request into the blockchain boundary.
5. Blockchain Core
Deterministic rules validate state, fees, signatures, transaction format and block inclusion.
6. Finality
Validators vote, quorum is checked and the finalized transaction becomes explorer-verifiable evidence.
Verified Boundaries
  • HEKA127 Brain advises; blockchain decides
  • RA pays network gas
  • RAK is handled as a separate ledger asset
  • Explorer reads finalized evidence
