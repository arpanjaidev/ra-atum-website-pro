RA ATUM Explorer

RA ATUM Website Pro

The Explorer is a read-only view of finalized chain evidence. It should make blocks, transactions, accounts, validators and both RA ATUM assets understandable without manufacturing missing data.

Blocks
Inspect finalized height, block hash, transaction set, Merkle root and validator evidence.
Transactions
Search finalized RA and RAK transfers with sender, receiver, amount, fee and proof.
Accounts
View RA gas and RAK reward balances separately for an RA ATUM address.
Assets
Read the canonical asset registry instead of hardcoding supply or treasury metadata.
Validators
Review validator membership and status from the chain's read surface.
Unknown Safety
Not Found remains Not Found; pending and finalized evidence must never be mixed.
Verified Boundaries
  • Read-only interface
  • Finalized RPC is authority
  • Future transactions should appear automatically
  • Synthetic data is forbidden
